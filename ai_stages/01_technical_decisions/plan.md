# Стадия 1. Технические решения

## Результат

Зафиксирован минимальный поддерживаемый сценарий и приняты решения, которые не придётся менять при реализации следующих стадий.

## План

1. Уточнить Windows 10/11 как целевую платформу и выбрать один монитор для MVP.
2. Принять Win32 API для изменения видеорежима и Qt 6 Widgets для интерфейса и процесса.
3. Определить контракт `DisplayModeService`: прочитать исходный режим, перечислить доступные, применить, восстановить.
4. Определить контракт `GameLauncher`: запуск прямого EXE, наблюдение за процессом, сигнал завершения/ошибки.
5. Выбрать INI рядом с EXE для portable-настроек: путь к игре, монитор, разрешение, опциональный Steam AppID.
6. Оценить статическую Qt-сборку против обычной portable-папки/упаковки и принять вариант для релиза.

## Проверка

Документированы решения и ограничения; CMake-сборка остаётся воспроизводимой на чистой машине разработки.
